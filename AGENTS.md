# Repository language

Keep committed documentation, README files, code comments, docstrings, configuration
descriptions, test messages, and generated human-readable inventories in English.
Use English for commit messages and GitHub repository descriptions as well.

Preserve scientific identifiers, sequences, source metadata, numeric results, commands,
and hashes when editing prose. Technical symbols and units do not need ASCII replacements.
Conversation with users may follow their preferred language outside repository content.

The core-release exporter rejects CJK ideographs in text files before publishing them.
This is a regression check for untranslated content, not a general-purpose language detector.
